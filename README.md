# Dioklecijan · Od purpura do vrta

Autorski WebAR kronovizor Miljenke Ćurković: Dioklecijan kao car, abdikacija i život u vrtu prema antičkoj anegdoti.

Demo sadrži latinski govor, hrvatski prijevod, povijesni kontekst i izvor. Prizori su autorska interpretacija antičkog teksta.

## Korištenje

Otvorite stranicu u mobilnom pregledniku. Snimku možete gledati bez kamere. Tipka **Otvori kameru** prikazuje kronovizor preko stražnje kamere; prozor možete pomicati i povećavati. Na podržanim uređajima **Postavi u prostoru** omogućuje postavljanje prozora na odabrano mjesto. **Krupni plan govora** približava vrtni prizor.

Kamera se uključuje samo na zahtjev. Mikrofon se ne koristi. Za pristup kameri potrebna je HTTPS poveznica.

## GitHub Pages

Projekt je statičan i ne zahtijeva instalaciju ni izgradnju. U postavkama repozitorija odaberite **Pages → Deploy from a branch → main → / (root)**. Datoteka `.nojekyll` omogućuje izravno posluživanje sadržaja.
